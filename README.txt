## Hi there and welcome to the Enagic Truth Discussion.
### Please click the Discussions tab above to view and add your answers to each of the common complaints haters have with Enagic.

Some more details if you care to read.

One day i was reading all the 1 start reviews of Enagic on the Trustpilot website and as i was reading i noticed that most of the posts seemed to be similar, almost as if the same person writes a lot of them. Of course i cant be sure if that's true but that got me thinking. 

Why don't we as as community of distributors team up and create the best most comprehensive responses to all of their complaints. We may not be able to answer all of them with proof but surely we as a community can some up with some amazing responses.

I thought that we can open source the answers and who ever can come up with the best response will be up-voted on by the community and become the leading answer. We can even merge responses together if we have 2 or more with lots of up votes. Then that will become the answer to each question. The best responses should have as much proof as possible, either links, pictures, videos, pdfs, whatever you can get.

This can be a resourse that we can use if we choose to engage with haters or even with prospects so that we are informed, that we arent just making stuff up.
